# Season Audit — Intake Template

Copy this into the conversation at Step 0. Replace `[...]` placeholders with user answers before proceeding.

```
SEASON AUDIT INPUTS
===================
Pillar Name:        [e.g., Maintenance]
Season Name:        [e.g., Summer 2026]
Season Dates:       [e.g., Feb 1 – May 31, 2026]
Planning Deck URL:  [Google Slides URL]
Discovery Project Key: [e.g., PROJ]
Season Jira Label:  [e.g., Summer2026]
Next Season Label:  [e.g., Fall2026]

Dev Teams:
  - [Team Name 1] → [GitLab project path 1]
    e.g., App Team → team-a/monorepo
  - [Team Name 2] → [GitLab project path 2]
    e.g., Data Team → team-b/data-pipeline

Stream Names:
  - [Stream 1 name, e.g., Work Order Management]
  - [Stream 2 name, e.g., Insights]

BI Dashboard:        [dashboard ID or URL, or "none"]
Output Directory:    [e.g., ~/projects/maintenance-summer-2026-recap/]
Pre-read Format:     [any special requirements, or "standard"]
```

## Minimum Viable Inputs

If the user is in a hurry, the absolute minimum to start is:
1. Pillar name
2. Season name + dates
3. Planning deck URL
4. Discovery project key + season label
5. At least one dev team + GitLab path

All other inputs can be inferred or skipped with noted gaps.
